# Antigravity 專案入口適配

- 共用規範依根目錄 `AGENTS.md` 及 `docs/agents/shared_context.md`。
- 角色只由 `docs/agents/skills_registry.md` 路由；本規則不複製必讀清單或角色表。

- 快速導航見 `AGENT_CONTEXT.md`；日期化狀態仍以主題權威文件為準。
