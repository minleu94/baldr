# R009 — schema-driven execution codec 與歷史 decoder

## TASK CONTEXT

現有DTO手工`to_dict/from_dict`同時支援中英文keys並散布欄位轉換。FINAL要求新格式只有一份typed schema與版本dispatch。

## WHY THIS TASK EXISTS

R012發布新writer前必須先證明新舊readback，並避免未來新增optional scalar漏存。

## AUTHORITATIVE ARCHITECTURE REFERENCES

- [FINAL_TARGET_ARCHITECTURE §6.1](../FINAL_TARGET_ARCHITECTURE.md)
- [FINAL_EXTENSIBILITY_MODEL §3](../FINAL_EXTENSIBILITY_MODEL.md)
- [FINAL_ARCHITECTURE_INVARIANTS INV-11](../FINAL_ARCHITECTURE_INVARIANTS.md)

## DEPENDENCIES

R004、R008。

## ALLOWED SCOPE

新增 `app_module/recommendation/codec.py`、codec tests；在舊DTO加薄委派/legacy dispatch seam但不刪API。

## OUT OF SCOPE

repository、SQL、save callers、任意dict extension、pickle、改欄位語意。

## CURRENT BEHAVIOR TO PRESERVE

舊English/Chinese keys、Decimal close price、calibration metadata、negative evidence、unknown optional defaults及原artifact bytes/hash驗證順序。

## IMPLEMENTATION OBJECTIVE

fields/annotations白名單遞迴codec；固定schema_version/revision；Decimal字串、int units、date/aware datetime、enum、tuple/mapping；legacy decoder唯讀。若舊 `app_module.dtos` import 必須暫留：

- `CREATED_TEMPORARY_COMPONENT: TMP-REC-05`
- `REMOVES_TEMPORARY_COMPONENT: R029`

已證實的 serialized qualified-name alias 改列永久相容，不得誤刪。

## ARCHITECTURAL INVARIANTS

INV-01、08、11、12、17。

## ML COMPATIBILITY REQUIREMENTS

ML projection作已定typed value/reference；codec不得導入trainer/model或重新解讀feature values。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

canonical UTF-8 bytes/hash規則固定；unknown revision/type拒絕；old artifact先驗hash再升版read view，不重寫原檔。

## TEST REQUIREMENTS

all-field roundtrip、deterministic bytes、null/0、Decimal不經float、offset time、old missing optional、new revision/old reader拒絕、legacy fixtures。

## ACCEPTANCE CRITERIA

新增typed optional field只需contract＋root revision，不改codec欄名單；沒有`asdict/__dict__`；舊fixtures可讀。

## EXPECTED DELIVERABLES

codec、version dispatch、legacy decoder tests、wire examples。

## POST-TASK REPORT REQUIREMENTS

報告每種型別wire、支援revisions、canonical hash、legacy差異與未發布writer狀態。

## ROLLBACK / FAILURE CONDITIONS

任一舊fixture丟欄、Decimal漂移或新reader改原bytes即停止。新writer未發布前可回滾codec接線。
