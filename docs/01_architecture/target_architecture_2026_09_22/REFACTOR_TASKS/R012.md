# R012 — create-only result artifact store、save 與 query

## TASK CONTEXT

現有repository在app層直接懂DTO/JSON/SQLite，普通save可replace。FINAL的新writer必須create-only，artifact為真值、SQLite為可重建index。

## WHY THIS TASK EXISTS

Qt/CLI/personalization/query consumers需要穩定save/load contract，且新schema發布後回滾政策不同於純code refactor。

## AUTHORITATIVE ARCHITECTURE REFERENCES

- [FINAL_TARGET_ARCHITECTURE §6.2](../FINAL_TARGET_ARCHITECTURE.md)
- [FINAL_DATA_FLOW §3](../FINAL_DATA_FLOW.md)
- [FINAL_MIGRATION_SEQUENCE Block 3](../FINAL_MIGRATION_SEQUENCE.md)

## DEPENDENCIES

R004、R009、R011。

## ALLOWED SCOPE

新增recommendation ports/persistence/save/queries與`data_module/result_artifact_store.py`；使舊repository/save coordinator委派或保留legacy入口。

## OUT OF SCOPE

刪replace、consumer cutover、generic repository、改business values、正式schema apply。

## CURRENT BEHAVIOR TO PRESERVE

storage paths、legacy read/list、personalization capture guard、orphan recovery、watchlist/ACK獨立outcome、明示保存。

## IMPLEMENTATION OBJECTIVE

codec產bytes/hash；low-level store只收bytes/hash/index metadata；exclusive create；same ID/hash冪等；異hash拒絕；metadata命令不改execution。為尚未切換的保存 caller 提供：

- `CREATED_TEMPORARY_COMPONENT: TMP-REC-03`
- `REMOVES_TEMPORARY_COMPONENT: R015`

最後一個保存 caller 必須在 R015 切換後才可移除此 bridge。

## ARCHITECTURAL INVARIANTS

INV-01、10–12、17。

## ML COMPATIBILITY REQUIREMENTS

receipt/projection refs逐字保存，不重新推論／解析active pointer。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

artifact durable後index transaction；file-only可補index；index無valid artifact不得可用；unknown/legacy bytes保留；新writer不fallback replace。

## TEST REQUIREMENTS

R004全部、codec、concurrent create、same/different hash、file/index failure、index rebuild、metadata rename、legacy fixture load、save-after-source-change。

## ACCEPTANCE CRITERIA

新save/query完全運作；data store無app import；JSON/SQLite failure可辨；legacy API未被新API隱性調用。

## EXPECTED DELIVERABLES

四個app modules、data store、adapters/tests、schema publication/rollback note。

## POST-TASK REPORT REQUIREMENTS

報告writer/readers、published revision、failure recovery、legacy entrypoints、是否產生任何artifact（只能tmp）。

## ROLLBACK / FAILURE CONDITIONS

新格式一旦在非tmp環境發布，rollback只能停writer並保留reader/artifacts；不得用舊replace覆寫。測試中任一identity/hash差異即停止。
