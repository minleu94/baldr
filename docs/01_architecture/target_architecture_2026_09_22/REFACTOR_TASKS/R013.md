# R013 — Qt recommendation consumer 遷移

## TASK CONTEXT

RecommendationView目前保存current list並於 `_build_current_result_snapshot`／`_save_recommendation_result` 讀 service.last_* 重組結果；execution coordinator回傳list。

## WHY THIS TASK EXISTS

UI是hidden-state與stale callback最直接風險；新execution存在後應只持同一sealed結果。

- [FINAL_ARCHITECTURE_INVARIANTS INV-09、10、16](../FINAL_ARCHITECTURE_INVARIANTS.md)

## DEPENDENCIES

R011、R012。

## ALLOWED SCOPE

Qt recommendation execution coordinator/view、必要presenter/model、其tests與Manual（若可見流程文字變更）。

## OUT OF SCOPE

core engine、save implementation、其他tabs、UI redesign、推薦公式。

## CURRENT BEHAVIOR TO PRESERVE

profile/request freeze、required pattern/indicator validation、progress/cancel、last-good result、stale callback防護、selection、save/watchlist訊息與欄位格式。

## IMPLEMENTATION OBJECTIVE

worker回傳RecommendationExecution；view只持sealed execution/read model；save同一object；presenter做格式，不組business payload。

## ARCHITECTURAL INVARIANTS

INV-07–10、16。

## ML COMPATIBILITY REQUIREMENTS

只呈現execution中既有projection/receipt status；缺值不補0，不觸發推論。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

Qt只呼叫new save command；不讀repository internals、不重查regime/context。

## TEST REQUIREMENTS

execution coordinator、recommendation presenter/metadata/profile；新增A→B→save A、cancelled不套partial、stale callback。跑repo規定UpdateView pytest、QA validator與mypy。

## ACCEPTANCE CRITERIA

production Qt path無business last_*、無RecommendationResultDTO重建；顯示與保存result_id相同；可見行為保持。

## EXPECTED DELIVERABLES

Qt cutover、presenter/tests、必要Manual更新。

## POST-TASK REPORT REQUIREMENTS

列出改動slots/signals、保存路徑、UI checks、仍使用legacy façade的非Qt caller。

## ROLLBACK / FAILURE CONDITIONS

若cancel/stale/save identity改變或強制UI check新增failure，切回舊caller但保留new execution API；不得回填last_*到新API。
