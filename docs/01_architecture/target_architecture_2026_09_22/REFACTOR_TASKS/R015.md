# R015 — personalization producer／save／ACK 遷移

## TASK CONTEXT

personalization script與save adapter將producer.last_run_context、result DTO、candidate capture、projection receipt及delivery ACK串在一起，並有嚴格create-only/CAS回歸。

## WHY THIS TASK EXISTS

它是保存與ML identity最敏感的consumer，需獨立切片，避免與Qt/scheduled同時修改save核心。

## AUTHORITATIVE ARCHITECTURE REFERENCES

- [FINAL_TARGET_ARCHITECTURE §5.2、§7](../FINAL_TARGET_ARCHITECTURE.md)
- [FINAL_MIGRATION_SEQUENCE Block 3、TMP-REC-03](../FINAL_MIGRATION_SEQUENCE.md)
- [FINAL_ML_COMPATIBILITY_CONTRACT §2](../FINAL_ML_COMPATIBILITY_CONTRACT.md)

## DEPENDENCIES

R011、R012、R013、R014。本任務必須等 Qt 與 scheduled 保存 caller 都切換，才能成為 TMP-REC-03 的移除者。

## ALLOWED SCOPE

personalization recommendation script/save adapter、legacy save coordinator caller seam、integration tests。

## OUT OF SCOPE

personalization calibration/retraining、label contract、delivery authority/journal schema、model promotion。

## CURRENT BEHAVIOR TO PRESERVE

scope/clock、candidate/model/training hashes、create-only、orphan recovery、retry exact readback、ACK CAS、writer failure/no ACK、UI host message。

## IMPLEMENTATION OBJECTIVE

execution提供producer scope/result/receipt；save/readback後另行ACK。retry載入同result，不重算、不降級既有personal capture。確認 Qt、scheduled 與 personalization 保存 caller 都已切換後，`REMOVES_TEMPORARY_COMPONENT: TMP-REC-03`；若仍有清冊內 caller，任務不得宣稱完成。

## ARCHITECTURAL INVARIANTS

INV-01、07、10、12、14、15。

## ML COMPATIBILITY REQUIREMENTS

ML_COMPATIBILITY_RISK：prediction/training provenance與receipt IDs/hashes逐字保持；不resolve新active pointer。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

same ID/hash idempotent、different hash拒絕；legacy personal artifact與unknown bytes保留；ACK metadata不進execution hash。

## TEST REQUIREMENTS

完整personalization save integration、recommendation calibration integration的save/readback區段、CLI/host smoke、race/retry/ACK failure。

## ACCEPTANCE CRITERIA

production path不讀producer.last_run_context；save與ACK outcome分離；全部hash/clock/receipt parity。

## EXPECTED DELIVERABLES

script/adapter cutover、tests、TMP-REC-03 caller closure更新。

## POST-TASK REPORT REQUIREMENTS

列出identity chain、retry/ACK cases、ML risk evidence、remaining legacy save callers。

## ROLLBACK / FAILURE CONDITIONS

任一identity/hash/CAS差異或舊personal result被覆寫即rollback；不得重新產生artifact掩蓋。
