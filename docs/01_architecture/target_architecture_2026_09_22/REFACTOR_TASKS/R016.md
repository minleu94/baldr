# R016 — saved-result query consumers 遷移

## TASK CONTEXT

AdviceComposer、DecisionDesk、watchlist/research、evidence importers各自使用RecommendationResultDTO或自行from_dict/load repository。

## WHY THIS TASK EXISTS

新artifact若仍被多個consumer各自decode，欄位與歷史語意會再次分裂；查詢必須集中。

## AUTHORITATIVE ARCHITECTURE REFERENCES

- [FINAL_DATA_FLOW §3–§4](../FINAL_DATA_FLOW.md)
- [FINAL_TARGET_ARCHITECTURE §7](../FINAL_TARGET_ARCHITECTURE.md)
- [FINAL_ARCHITECTURE_INVARIANTS INV-10–13](../FINAL_ARCHITECTURE_INVARIANTS.md)

## DEPENDENCIES

R011、R012。

## ALLOWED SCOPE

saved recommendation readers：Advice、Decision Desk、watchlist analysis、evidence importer/replay與其tests。以queries/read view適配原consumer API。

## OUT OF SCOPE

改advice/portfolio/evidence business policy、UI layout、保存writer、重新計分/推論。

## CURRENT BEHAVIOR TO PRESERVE

result_id/source trace、included/negative evidence、as-of selection、old artifact display、missing field behavior、read-only evidence import。

## IMPLEMENTATION OBJECTIVE

所有reader經唯一query/codec驗證execution，再產consumer-specific read model；不查今日data/regime/model。

## ARCHITECTURAL INVARIANTS

INV-01、10–13、17。

## ML COMPATIBILITY REQUIREMENTS

只呈現保存時projection/receipt；不能重新load model或補annotation。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

old decoder永久保留；原bytes/hash不變；unsupported明示，不猜欄。

## TEST REQUIREMENTS

Advice composer、decision desk source/read model、watchlist analysis、evidence importer/pipeline、historical evidence replay及old fixture tests。

## ACCEPTANCE CRITERIA

consumer不直接from_dict/load raw JSON；new/old結果輸出parity；無live lookup。

## EXPECTED DELIVERABLES

query adapters、consumer cutovers、tests與reader清冊更新。

## POST-TASK REPORT REQUIREMENTS

列出所有reader、read model、old formats、無重算證據。

## ROLLBACK / FAILURE CONDITIONS

歷史結果顯示改變或consumer需改policy才能讀時，回切該adapter並回報，不在此task修policy。
