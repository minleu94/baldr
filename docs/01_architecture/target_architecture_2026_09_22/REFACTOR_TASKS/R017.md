# R017 — replay canonical bridge

## TASK CONTEXT

Replay現以`List[Dict]`與RecommendationSnapshotDTO傳遞，與interactive RecommendationDTO不同。此task只把現況封裝成canonical execution，不改算法。

## WHY THIS TASK EXISTS

直接在R020同時改shape與算法會無法判斷回歸來源；需要先建立TMP-REC-04橋接。

## AUTHORITATIVE ARCHITECTURE REFERENCES

- [FINAL_MIGRATION_SEQUENCE Block 3、TMP-REC-04](../FINAL_MIGRATION_SEQUENCE.md)
- [FINAL_DATA_FLOW §4](../FINAL_DATA_FLOW.md)
- [FINAL_ARCHITECTURE_INVARIANTS INV-07、13、17](../FINAL_ARCHITECTURE_INVARIANTS.md)

## DEPENDENCIES

R005、R009、R011。

## ALLOWED SCOPE

RecommendationDataFrameProvider/ReplayService/SnapshotDTO的橋接與tests；外層backtest API可維持。

## OUT OF SCOPE

共用decision evaluator、改replay policy、改portfolio backtest、保存正式child artifacts。

## CURRENT BEHAVIOR TO PRESERVE

R005全部：cutoff/lookback/candidate limit/fast filters/score fallback/sort/topN/skip/empty/factor manifest。

## IMPLEMENTATION OBJECTIVE

將legacy rows轉typed items/DecisionBatch/child execution，記profile/config/date/policy及parent refs；不補不存在欄位。

- `CREATED_TEMPORARY_COMPONENT: TMP-REC-04`
- `REMOVES_TEMPORARY_COMPONENT: R020`

Bridge 不得承載第二套評分規則。

## ARCHITECTURAL INVARIANTS

INV-05–09、13、17。

## ML COMPATIBILITY REQUIREMENTS

舊replay無ML值就保持None/unavailable；不得以現在模型補值。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

橋接只在memory/tmp manifests；若外層序列化，須透過R009 codec並保留舊snapshot reader。

## TEST REQUIREMENTS

R005/V-REPLAY、bridge roundtrip、new result/parent ID、empty/error、legacy snapshot projection。

## ACCEPTANCE CRITERIA

外部replay/backtest結果不變；每snapshot有typed child execution；TMP-REC-04有R020刪除路徑。

## EXPECTED DELIVERABLES

bridge、typed refs、tests、TMP登錄。

## POST-TASK REPORT REQUIREMENTS

列出mapping、未能typed表達的欄（若有即blocker）、policy未變證據。

## ROLLBACK / FAILURE CONDITIONS

任何replay numeric/order/candidate差異即回切legacy dict；不修改golden或共用evaluator。
