# R018 — 推薦 input preparation／provider 抽離

## TASK CONTEXT

RecommendationService目前自行載入market frame、historical cutoff、fundamental SQLite/PIT membership並決定fallback/context。Consumers已在R013–R017改接execution後，才能安全抽來源責任。

## ALLOWED SCOPE

## OUT OF SCOPE

app明示resolve/prepare；data providers只讀來源並回SourceObservation/MarketSlice或窄input records；service不自行construct hidden providers。

## TEST REQUIREMENTS

## ACCEPTANCE CRITERIA

RecommendationService不直接查推薦資料來源；所有fallback可見；同fixture execution內容完全一致。

## EXPECTED DELIVERABLES

input preparation modules/ports、composition wiring、central service縮減、tests。

## POST-TASK REPORT REQUIREMENTS

## ROLLBACK / FAILURE CONDITIONS
