# R019 — 純推薦 evaluator 抽離

## TASK CONTEXT

R018後RecommendationService應已有完整inputs，但filter、factor、scoring、ranking、reasons、negative evidence仍在legacy body。FINAL將其owner定為decision。

## WHY THIS TASK EXISTS

本 task 完成單一 rule engine 與 domain no-I/O，使 replay 可共用。原始任務文字曾把 `TMP-REC-01` 寫成整個 private body／invocation capture；依 2026-09-24 的責任拆分，R019 只關閉 legacy state/matrix 到 canonical **rule** outputs 的 bridge，app source-orchestration body 與 execution telemetry capture 不屬於此移除範圍。

## DEPENDENCIES

R018、R023、R024。

## ALLOWED SCOPE

## OUT OF SCOPE

## CURRENT BEHAVIOR TO PRESERVE

## IMPLEMENTATION OBJECTIVE

單一 pure evaluator 接 typed inputs/policy 並直接產生 DecisionBatch；app 組 execution/ML。移除透過 capture 的 `last_*`／legacy matrix 重建 canonical rule DecisionBatch、assessment、item 與 rule-context 的路徑，public façade 仍可投影。`REMOVES_TEMPORARY_COMPONENT: TMP-REC-01 (narrow legacy-state/matrix-to-canonical-rule bridge only; CLOSED by C3B/C3C2/C3C3 and parity gate)`。不移除 app 私有 source-orchestration body；invocation clocks/error/progress 仍由 app execution telemetry capture 提供，ML availability/projection receipt 由 `TMP-ML-01`／R026 列管。TMP-NUM-01 只有在獨立數值等價證據完整時才可關閉，否則交 R029 明示列管。

## ACCEPTANCE CRITERIA

只有一個 rule evaluator；decision modules 不 import app/data concrete/Qt/scripts；legacy state/matrix→canonical rule bridge 已 bounded CLOSED；app source orchestration/capture 仍按各自 owner 保留；numeric差異為零。

## EXPECTED DELIVERABLES

decision evaluator modules、wiring、移出／停用 legacy pure rule decision path、tests 與 `TMP-REC-01` 窄 bridge closure。保留尚負責 source orchestration 的 app private body 及 execution telemetry capture，直到對應來源／ML 路徑另有核准移交。

## Scope clarification（2026-09-24）

R019 原始 `WHY`／`REMOVES` 將 REC-01 概括成 private body 加 invocation capture 的整體退役；C3B、C3C2、C3C3 與 parity gate 驗收後，REC-01 僅以 legacy `last_*`／matrix 對 canonical rule DecisionBatch、assessment、item、rule-context 的橋接定義並標 CLOSED。此修改保留原單一 evaluator/no-I/O 的設計理由，但不將私有 body、execution clocks/error/progress、ML availability 或 receipt capture 宣稱已移除，也不關閉 `TMP-REC-02`／`TMP-NUM-01`。clock/error/progress 屬 app execution telemetry；ML availability/projection receipt 由 `TMP-ML-01`／R026 列管。
