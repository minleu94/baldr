# R020 — replay 共用 evaluator 與版本化 policy

## TASK CONTEXT

R017先用bridge保留DataFrame replay；R019提供唯一pure evaluator。現在才可用明示policy取代重複評分body。

## WHY THIS TASK EXISTS

目標是共用業務規則而保留 mode 差異，並移除 TMP-REC-04 所代表的內部 DataFrame row-dict engine／bridge。這不移除外層 `RecommendationSnapshotDTO.recommendations` v1 list：它仍是 live compatibility projection，現存 portfolio 與 factor-manifest consumers 須保持可用。

## DEPENDENCIES

R017；R019 evaluator core bounded `ACCEPTED_SCOPE`（C3B/C3C2/C3C3 與 parity gate）。此 dependency 不要求 `TMP-REC-02` list/latest-state 或 v1 event/callback compatibility outputs 退場，也不要求 ML telemetry/capture 遷移；後者由 `TMP-ML-01`／R026 列管。R020 仍須遵守自身執行順序與其他適用 gate。

## Scope clarification（2026-09-24）

原 dependency 的 `R019` 指 evaluator core，而非整個 R019 task、REC-02 compatibility output retirement 或完整 invocation capture removal。此處的「row schema」僅指內部 DataFrame row-dict engine／bridge；外層 `RecommendationSnapshotDTO.recommendations` v1 list 是 live compatibility projection，portfolio 與 factor-manifest consumers 仍使用，必須保留。此說明使 R019 evaluator core 的 bounded acceptance 成為明確依賴 gate，不替 R020 宣告自身驗收完成。

### Replay-only post-score evaluator scope（2026-09-24）

R020 可在既有 `RecommendationEvaluator` 增加 replay-only typed post-score phase；replay provider 可用 call-local config 副本（移除 `filters`）呼叫 scorer，原始 config 仍用於建立 versioned policy／receipt。此範圍不改 `StrategyConfigurator` 或 interactive `RecommendationService` 的 source、API 與預設行為；replay 的 post-score filter 決策只由 typed evaluator phase 擁有。custom／overridden scorer 若無法提供同一 typed handoff，須明示維持 v1-only／無 canonical child 或 fail closed。實作仍須通過 invalid-threshold 時點、20-row volume fallback、RSI、filter aliases 與同模式輸出 parity。此段只授權受控 replay 實作，不代表 R020、TMP-REC-04、C2 關閉，也不宣稱 FINAL 架構的互動／回放跨模式全域統一已完成。

## ALLOWED SCOPE

Replay/DataFrame provider/replay policy/input adapter、Snapshot projection及portfolio integration tests。

## OUT OF SCOPE

## IMPLEMENTATION OBJECTIVE

Replay preparation 產 typed inputs＋versioned policy，呼叫 R019 evaluator；外層 Snapshot 引用 child execution。退役 TMP-REC-04 的內部 DataFrame row-dict engine／bridge，不維護第二套內部 replay row-dict schema；保留 `RecommendationSnapshotDTO.recommendations` v1 list live compatibility projection，供現存 portfolio 與 factor-manifest consumers 使用。`REMOVES_TEMPORARY_COMPONENT: TMP-REC-04`；同時關閉 TMP-NUM-01 中僅屬 legacy replay row-dict 計算／轉換 bridge 的子範圍，其他既有浮點算法仍需獨立 gate。
