# R021 — StockScreener concrete I/O 移至 data provider

## TASK CONTEXT

`decision_module/stock_screener_sqlite_reader.py`直接處理SQLite；StockScreener仍有CSV self-loading fallback。FINAL要求domain無concrete I/O。

## WHY THIS TASK EXISTS
