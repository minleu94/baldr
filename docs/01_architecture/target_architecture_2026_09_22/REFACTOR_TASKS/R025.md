# R025 — strategy contracts／registry／executors 移至 decision

## TASK CONTEXT

`StrategySpec`、`StrategyMeta`、`StrategyExecutor`、`DailySignalFrame`、registry 與既有 executors 目前由 `app_module` 擁有，但 Backtest、optimizer、UI 與 scripts 都把它們當成 domain contract 使用。

## WHY THIS TASK EXISTS

策略定義與執行契約必須由 decision layer 擁有，application 才能只負責組合依賴與 use case。這是責任搬移，不是策略公式或產品行為改版。

## AUTHORITATIVE ARCHITECTURE REFERENCES

- [FINAL_TARGET_ARCHITECTURE §4–§5](../FINAL_TARGET_ARCHITECTURE.md)
- [FINAL_EXTENSIBILITY_MODEL 的 strategy extension](../FINAL_EXTENSIBILITY_MODEL.md)
- [FINAL_MIGRATION_SEQUENCE Block 4 與 temporary retirement ledger](../FINAL_MIGRATION_SEQUENCE.md)
- [FINAL_ARCHITECTURE_INVARIANTS INV-02–06、INV-14](../FINAL_ARCHITECTURE_INVARIANTS.md)

## DEPENDENCIES

R001、R005。

## ALLOWED SCOPE

新增 `decision_module/strategies/`；搬移 strategy contracts、registry 與現有 executors；調整 Backtest、optimizer、Qt、scripts、tests 的 imports 與 composition；在無法一次切換已知 source caller 時加入已登錄的薄 re-export。

## OUT OF SCOPE

修改策略公式、threshold、signal shape、fixed／quantile 語意、look-ahead 規則、lifecycle／promotion、建立 plugin discovery 或新增 production strategy。

## CURRENT BEHAVIOR TO PRESERVE

三個既有 strategy IDs 與 metadata、registry duplicate 拒絕、`DailySignalFrame` validation、參數 round-trip、fixed／quantile 行為、排序與 tie-break、Backtest／walk-forward 結果及 UI strategy list。

## IMPLEMENTATION OBJECTIVE

使 decision 成為 strategy contract、registry 與 executor 的單一 owner；app、Backtest、optimizer、UI 與 scripts 只透過該契約使用策略。若 caller 支援期要求 app re-export：

- `CREATED_TEMPORARY_COMPONENT: TMP-STR-01`
- `REMOVES_TEMPORARY_COMPONENT: R029`

建立前必須先把精確 caller、owner、退出條件補入 temporary retirement ledger。

## ARCHITECTURAL INVARIANTS

INV-02–06、INV-14。不得留下兩份 registry、兩份 executor body 或 central strategy `if/elif` dispatch。

## ML COMPATIBILITY REQUIREMENTS

不改 ML features、eligibility、projection 或 artifact。若 strategy output 是 ML candidate identity 的輸入，必須以既有 fixtures 證明 candidate IDs、順序及決策日期完全一致。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

既有 `StrategySpec` serialized keys、defaults、qualified-name 相容需求與參數 round-trip 不變。已證實被留存 artifact 引用的 class alias 應列為永久相容，不可誤標為 TMP-STR-01。

## TEST REQUIREMENTS

執行 strategy threshold／params／registry、Backtest、walk-forward、optimizer 與 UI strategy-list focused tests；增加 duplicate registration、contract import direction 與 legacy spec round-trip 測試；以 R001 caller 清冊驗證已知 caller 全部切換或明列 TMP-STR-01。

## ACCEPTANCE CRITERIA

decision 是唯一 strategy runtime owner；三個既有策略輸出 parity；沒有第二 registry 或演算法複本；所有 caller 有明確新 import 或具名 temporary entry；dependency guard 不出現 decision→app 逆向邊。

## EXPECTED DELIVERABLES

decision strategy package、更新後 caller wiring、focused tests、caller migration report；如有需要，含 TMP-STR-01 登錄與 removal evidence checklist。

## POST-TASK REPORT REQUIREMENTS

列出搬移 symbols、caller、策略輸出 parity、序列化 qualified paths、未切換 caller、TMP-STR-01 狀態及本任務未改動的策略語意。

## ROLLBACK / FAILURE CONDITIONS

任何策略輸出、排序、參數 round-trip、Backtest 結果或 look-ahead 邊界差異都需回滾。可暫時切回單一舊 owner；不得以保留雙 registry 或雙 executor 作為回滾。
