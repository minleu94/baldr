# R027 — technical publication／ML identity 隔離實驗

## TASK CONTEXT

`UpdateService.calculate_technical_indicators` 可能同時影響 technical publication 時序與 Direct computation source identity。FINAL 架構將其安全性標為 `NEEDS IMPLEMENTATION EXPERIMENT`，尚未授權搬移。

## WHY THIS TASK EXISTS

在碰 production wiring 前，必須以彼此獨立的舊／候選執行與隔離 fixtures 證明 orchestration 搬移是否透明，或明確判定不相容。

## AUTHORITATIVE ARCHITECTURE REFERENCES

- [FINAL_ML_COMPATIBILITY_CONTRACT §7](../FINAL_ML_COMPATIBILITY_CONTRACT.md)
- [FINAL_MIGRATION_SEQUENCE「獨立實驗：technical publication 搬移」與 TMP-ML-02](../FINAL_MIGRATION_SEQUENCE.md)
- [FINAL_ARCHITECTURE_INVARIANTS INV-09–12、INV-17](../FINAL_ARCHITECTURE_INVARIANTS.md)

## DEPENDENCIES

R006。

## ALLOWED SCOPE

新增隔離 experiment harness、synthetic fixtures、只讀 inventory／fingerprint checks 與 QA 報告；只讀檢視 `update_service.py`、technical producer、Direct dependency identity 與 resume/checkpoint 行為。

## OUT OF SCOPE

修改 production、正式資料、scheduler、full rebuild、模型／feature、Direct 15-path 清單、hash 定義、checkpoint 或 artifact。

## CURRENT BEHAVIOR TO PRESERVE

目前 source-relative paths、source-code fingerprint、runtime integrity、numeric bytes、rows／masks、warmup、publication／commit 時序、cancel、resume 正反例與失敗恢復。

## IMPLEMENTATION OBJECTIVE

產生可重跑的獨立實驗與結論：`PASS`、`FAIL` 或 `INCONCLUSIVE`。本任務負責登錄既有凍結例外與實驗接線：

- `CREATED_TEMPORARY_COMPONENT: TMP-ML-02`
- `REMOVES_TEMPORARY_COMPONENT: R028（僅限 R027=PASS）`

R028 僅在 PASS 時移除受證明可退休的 runtime 例外；FAIL／INCONCLUSIVE 時依 `AB-ML-01` 保留並升級。

## ARCHITECTURAL INVARIANTS

INV-09–12、INV-17。舊與候選不得共用新 helper 產生 oracle，不得對正式 storage 雙寫。

## ML COMPATIBILITY REQUIREMENTS

`ML_COMPATIBILITY_RISK: CRITICAL`。在獨立 process 比較完整 path set、每檔 SHA、source fingerprint、runtime integrity、feature bytes／shape／dtype／mask、publication timestamps、resume checkpoint 與下游 identity。只有全部條件完全相等才可 PASS。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

只使用隔離 temporary fixtures；不得建立或變更正式 DB、manifest、checkpoint、model artifact。測試產物需標出 schema、hash、產生程式與可安全清除範圍。

## TEST REQUIREMENTS

至少涵蓋 clean run、partial/resume、source unchanged、source changed、cancellation、publication failure 與同輸入重跑；加入 negative control，確保改 path、byte、timing 或 resume state 時實驗會失敗。

## ACCEPTANCE CRITERIA

報告含環境、commands、兩條獨立路徑、完整比較與明確 verdict；PASS 必須無例外差異；FAIL／INCONCLUSIVE 必須建立 `ARCHITECTURE_BLOCKER: AB-ML-01`，不得啟動 R028。

## EXPECTED DELIVERABLES

隔離 experiment harness、fixtures、可重跑指令、identity／timing comparison report、verdict 與 TMP-ML-02／AB-ML-01 狀態。

## POST-TASK REPORT REQUIREMENTS

列出 process isolation、inputs、paths、hashes、bytes、timing、resume cases、negative controls、verdict、證據位置與 R028 是否解鎖。

## ROLLBACK / FAILURE CONDITIONS

實驗可移除但證據報告保留。任何共享 helper、正式資料接觸、無法重現、比較欄位缺失或差異都不得判 PASS；應標 FAIL／INCONCLUSIVE 並保留現有 runtime。
