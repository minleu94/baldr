# R028 — 條件式 technical publication orchestration 遷移

## TASK CONTEXT

本任務只處理 R027 已以隔離實驗證明透明的 technical publication orchestration 搬移；它不是一般 Block 4 搬檔，也不是預設必做項。

## WHY THIS TASK EXISTS

若身份、數值與時序可被證明相容，跨服務協調應由具名 app job 擁有，而 data layer 保留 reader／writer 與純資料責任。

## DEPENDENCIES

R027 的 verdict 必須是 PASS。FAIL 或 INCONCLUSIVE 時本任務保持 blocked，並依 `AB-ML-01` 處理。

## ALLOWED SCOPE

`app_module/update_service.py`、新具名 application job、technical producer／composition、最小 caller wiring 與 affected tests；沿用 R027 已驗證的 production-equivalent call graph。

## OUT OF SCOPE

公式、warmup、writer 格式、Direct 15 paths、source hash／checkpoint 定義、正式 scheduler 啟用、full rebuild、模型或 feature schema 變更。

## CURRENT BEHAVIOR TO PRESERVE

technical values／bytes、row／mask、source identity、publication／commit／cancel 次序、feature materialization clock、resume 與 failure recovery。

## IMPLEMENTATION OBJECTIVE

把已證明透明的跨服務 orchestration 移至具名 app job，data 保留 reader／writer；重跑 R027 oracle 後，`REMOVES_TEMPORARY_COMPONENT: TMP-ML-02` 僅指受本遷移取代的 runtime 例外與實驗接線，歷史 artifact reader／必要 class alias 不刪。

## ARCHITECTURAL INVARIANTS

INV-02–05、INV-09–12。app 可協調，data 不得 import app；禁止以第二 writer 或雙 production path 作為長期相容。

## ML COMPATIBILITY REQUIREMENTS

`ML_COMPATIBILITY_RISK: CRITICAL`。production patch 必須重跑 R027 全部 hash／bytes／timing／resume oracle；任何 source path 或 fingerprint 改變都代表原 identity 不再成立，不能靜默接受。

## PERSISTENCE COMPATIBILITY REQUIREMENTS

publication storage schema、atomicity、resume checkpoint、manifest 與 failure recovery 不變；不得觸碰正式資料。舊 artifact 仍使用原 decoder／loader。

## TEST REQUIREMENTS

R027 全套實驗、Update focused tests、writer atomicity、cancel／resume、partial failure、dependency direction 與 caller smoke；必須包含 production call graph 的 negative control。

## ACCEPTANCE CRITERIA

具名 app job 是唯一 orchestration owner；data 僅保留資料 ports；所有 identity／numeric／timing checks 完全一致；原 runtime 接線與對應 source-path 例外只在有證據時移除。

## EXPECTED DELIVERABLES

具名 app job、composition wiring、focused tests、R027 production-equivalent rerun report、TMP-ML-02 retirement evidence 或明確 rollback report。

## POST-TASK REPORT REQUIREMENTS

列出搬移 calls、writer ownership、所有 hash／bytes／timing 比較、resume cases、移除的例外、永久相容保留項與正式 scheduler 未啟用的證據。

## ROLLBACK / FAILURE CONDITIONS

任一 R027 oracle、Update test、identity、timing、resume 或 failure-recovery 差異立即切回原單一路徑並恢復 TMP-ML-02 列管；不能重算 hash、放寬比較或保留雙 writer。
