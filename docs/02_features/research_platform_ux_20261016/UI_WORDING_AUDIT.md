# 介面用詞與資訊分層候選清單

2026-10-15｜工作樹靜態抽樣，未執行 GUI、未套用文字修改，不是全 UI 盤點。目標為一般股票使用者可直接判讀、新手友善、老手可深入。這些候選仍須和真正畫面／來源一起驗證。

原則：主畫面用用途與金融含義命名；工程代號留來源詳情。每卡一句判讀、關鍵圖形／數值、主要限制及一個主要動作。日期、期限、估計／模擬與成本就近保留。錯誤說明「發生什麼／影響／可做什麼」，不能用改字掩蓋缺乏恢復功能。
