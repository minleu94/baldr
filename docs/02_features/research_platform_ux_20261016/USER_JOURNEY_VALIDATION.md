# 圖卡、研究與紀錄：試用腳本

2026-10-15｜未執行的提案。主要對象是懂股票基本概念、但不懂程式的一般使用者；另觀察深入研究者與股票概念較少的人。三組使用同一套頁面，分開記錄，不設教學闖關。

先安排 2–3 人各約 30 分鐘，按其日常動機選三個核心任務及一個分支。先問最近一次為什麼查股票、用什麼工具、卡在哪裡。不要預告按鈕名稱；先觀察，必要協助另記。這是質性試用，不能估算市場完成率，也不代替原真人接受；放聲思考耗時和正式無干預計時分開。[方法參考](https://www.nngroup.com/articles/thinking-aloud-the-1-usability-tool/)

| 任務 | 給受測者的話 | 觀察重點 |
|---|---|---|
| 掌握市場 | 今天想先研究什麼？從畫面找線索 | 看出日期、範圍與變化；資料不足時可以暫不判斷 |
| 產業找股 | 找一個想了解的產業，再挑一家公司 | 分清產業與題材、強弱期間與分母；公司頁保留原脈絡 |
| 候選比較 | 挑兩檔值得研究的股票，說明理由 | 入選與排序可理解；看得到支持和反證；第一名不被當成買進指令 |
| 查證優缺點 | 找一個支持理由和一個疑點 | 摘要本身有用；能查原依據並返回同股、同源、同條件 |
| 判讀報酬 | 這幾個報酬數字各在說什麼？ | 分清歷史模擬、模型估計、機率、個人帳；知道期限成本；缺值不等於零 |
| 檢視持倉 | 在教學帳找指定部位，看看哪些事需確認 | 不以先跑回測為前置；帳本、估值日清楚；缺評估不等於安全 |
| 保存回訪 | 保存這次研究，關閉後找回來 | 理由可選填；原研究可重開，另看目前資料不覆寫；收藏不是交易或持有 |

每項記錄能否完成、第一次走向、求助次數、誤解原話、金融含義是否讀對、是否丟失上下文。嚴重誤讀需修正重驗，不能用平均成功率抵銷。保留原 3–5 位非技術者、30 秒判讀／2 分鐘進個股收藏及適用完整旅程要求。[原驗收](../../../docs/superpowers/plans/baldr_product_completion_plan_20261006.md:898)

## 原型與候選分開驗

首頁／產業／個股概念稿只測資訊安排與理解；明示虛構示例，不驗金融效果，也不證明產品已有畫面。

固定 71 可在目前電腦做受控試用：四股價格截至 2026-09-23，大盤截至 2026-10-14，依賴本機封存路徑。不能直接複製給受測者當安裝包。主持者先準備具名隔離狀態、確認不接正式資料／私人帳；本次未執行準備或修改 launcher。[71 指南](../../../output/trial/Baldr-Daily-Research-71/TRIAL_GUIDE.md)

71 可測四股搜尋、來源四檔與篩選結果的區別、兩股比較、單檔收藏／重開，以及隔離教學持倉下鑽。策略分支限已交付功能；完整產業地圖、模型機率、新首頁不能借此宣稱驗過。Increment72 不在71，遇原歷史缺件仍記作71限制。[版本界線](../../../docs/07_guides/TRIAL_VERSION_GUIDE.md:34)

隔次回訪可檢查找回原研究與辨認日期，不能視為自動更新／移機測試。錄影先取得受測者同意，使用教學資料。本次未聯絡或招募任何人。

## 回饋如何改變下一張工作卡

- 找不到答案：補首屏內容與主次，不先增加教學。
- 看得懂但進錯頁：修來源和導航，不只換按鈕名。
- 能操作但誤讀報酬：修種類、期間、成本及相鄰風險呈現。
- 老手找不到依據：保留直接研究入口及完整明細。
- 新手卡在少量名詞：補就近短解釋，依觀察決定是否增加引導。
- 保存後找不回：先修原研究身份和回訪，再考慮更多提醒。

每次修一條完整旅程並交付可試版本。來源、全市場、效能與金融證據門檻仍依原計畫。
