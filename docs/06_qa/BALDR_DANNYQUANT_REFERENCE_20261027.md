## 可見的清晰度線索

- 每日選股同時標示「今日名單」、「套用篩選後」、「資料完整」數量，後續又分開顯示模型池、符合條件及權限解鎖列數；篩選區說明可調條件，表格區說明資料更新時段與現價延遲。
- 個股研究頁說明全市場範圍、符合總數與目前顯示列數，搜尋欄明示可輸入代號或名稱。
- 首頁把策略條件、回測期間、風險限制與免責說明分開呈現；這是資訊分組參考，不代表其研究值已由 Baldr 驗證。

## 延遲證據與界線

- DannyQuant 公開每日選股頁在本次檢視呈現 0 筆及「正在讀取資料池」，個股研究頁顯示 1,996 筆符合、其中 100 筆列出；公開讀取結果沒有提供瀏覽器 Navigation Timing、穩定完成事件或可重複的會員資料負載。因此本次**沒有 DannyQuant 的延遲數字**，也不把頁面擷取結果當成完成畫面的計時。
- Baldr 本輪一項數值效能 A/B 是本機暫存檔案樹的 Storage Overview 盤點，4000 個檔案加 junction，p50 90.8447→12.1794 ms、p95 97.8380→14.1697 ms，輸出 digest 相同。這是單機檔案 metadata 路徑，與網站網路請求或 UI 載入結果不可直接比較。
- 已有 [TAIEX 歷史頁延遲基線](BALDR_TAIEX_HISTORY_LATENCY_BASELINE_20261027.md)量測 Baldr 本機 worker／圖表完成時間；同樣不可與外部網站端到端延遲直接比較。
- 策略庫版本讀取 QA 以阻塞合成 reader 證明讀取期間事件迴圈仍能處理 Qt 事件；它沒有量保存版本的完整載入耗時，也不代表目前正式版本檔數量或延遲。
- 2026-10-27 重新檢視[每日選股頁](https://www.dannyquant.com/signal-lottery-preview)仍看到「今日名單／套用篩選後／資料完整」計數及「正在讀取資料池」，並分開標示訊號更新時段與現價延遲；[個股研究頁](https://www.dannyquant.com/stock)顯示符合總數與目前列數。這是當下公開頁狀態，不提供可重複的載入完成時間。
- Baldr 的 [Research Timeline Journal 重用 QA](BALDR_RESEARCH_TIMELINE_JOURNAL_SNAPSHOT_REUSE_20261027.md)量得 6,000 筆合成 JSONL 的刷新至模型更新 p50/p95 610.6/737.5 ms→335.1/436.3 ms；全樣本輸出 digest 相同，四個 lane 的 Journal JSONL 讀取由 4 次降為 1 次。此本機合成/offscreen 結果不與 DannyQuant 網頁速度作數值對比。

## 後續比較規則

要形成公平的速度比較，需指定同一類操作、明確的資料筆數與完成畫面，並用相同操作定義從輸入到結果穩定呈現量 p50／p95；記錄硬體、網路、快取與登入狀態。能取得 DannyQuant 可重複操作及其完成事件後，再建立端到端比較；目前不依公開頁面資料量或外部擷取時間推論其互動速度。
