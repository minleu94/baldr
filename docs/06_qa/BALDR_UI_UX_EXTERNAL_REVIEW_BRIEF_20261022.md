## 1. 我們真正想做的產品

主要使用者是「知道股票是怎麼回事，但不必懂資料工程或量化模型」的人；同時對初學者友善，讓老手可以深入研究。不是以股票完全零基礎的教學平台為中心，也不是只有技術人員看得懂的工具箱。

希望第一眼就能掌握大盤、值得研究的股票、支持與反證、獲利證據及風險；有興趣再深入，最後保存自己的判斷、回訪及追蹤。不要靠大量說明文字，也不要為看一個答案不斷下鑽。

參考的是 DannyQuant 的資訊表達方向，不要求照抄外觀：

- 選股與訊號：<https://www.dannyquant.com/signal-lottery-preview>
- 產業地圖：<https://www.dannyquant.com/industry-map>
- 個股研究：<https://www.dannyquant.com/stock>

本文件未重新瀏覽這三個網站；請 reviewer 實際開啟再比較，勿把我們對參考網站的描述視為其當前功能。使用者先前的深色工作台圖片是「示意稿」，不是目前產品截圖。

## 3. 每條使用路徑現在如何呈現

以下是實作盤點，不是美觀評分。「待審」表示本次需要獨立檢視，並非已判定有缺陷。

| 路徑 | 目前呈現與操作 | 視覺化進度 | 請重點審查 |
|---|---|---|---|
| 今日總覽 | 風險、市場、候選、資料影響四主卡；題材強弱端與覆蓋、最近研究、短待辦；候選明選後進個股 | 已有卡片與題材觀察摘要；部分情境仍缺市場來源 | 第一屏是否回答「今天看什麼」？候選可用時題材／最近研究要下捲，優先順序合理嗎？ |
| 市場分析 | 大盤指數、強弱個股／產業、流向與研究母體等既有頁面，與產業題材入口並存 | 有既有市場展示；本輪沒有逐頁做新視覺驗收 | 是否仍像多個工具拼接？市場→產業→股票是否需要反覆切頁？不可推定每頁都有新圖卡。 |
| 產業與題材 | 原鏈→題材→成員；同版高低端觀察、覆蓋分母、原值長條；觀察與成員可對照；開股後可返回 | 已有雙端比較與零中線長條；缺資料不畫成零 | 是否達到「地圖一眼懂」，還是主要仍是表格？強弱、成交金額與法人覆蓋能否分清？ |
| 綜合選股 | 範本、日期、漏斗、結果優先；來源準備及進階條件收合；保留原查詢按鈕與保存條件 | 結果表、原母體計數；比較有支持／反證／未知 | 命中理由是否足夠白話？普通使用者能否知道何時需要「套範本」與「執行查詢」？ |
| 股票比較 | 原條件、不同來源日期及原分母保留；支持、反證、未知分列；可回到原選列／比較籃 | 有證據比較面板；沒有跨域混算共同分數 | 是否真的方便選出值得追蹤的股票，還只是把更多資料並排？ |
| 個股總覽／價量技術 | 緊湊股票身份、章節入口、保存與返回；價格／量／MA及五問摘要、支持／反證同屏 | 已有價量圖、技術線與報酬研究文字 | 摘要能否十秒內理解？多種日期、資料限制及來源提示是否壓過研究內容？ |
| 個股營收／基本面 | 在「基本面與營收」章節先放已核期間基礎的原值圖卡、財報當期／前期，再列原表 | **新完成原值橫條／單點值卡與財報比較**；不是完整月營收趨勢儀表板 | 橫條是否是最佳圖型？是否該用月份柱狀／同期對照？營收、毛利率等需不需要摘要頁預覽？ |
| 個股法人／信用 | 在「籌碼與產業事件」章節，法人淨額可同圖，買進、賣出、信用餘額等分開；原表保留 | **新完成同日原值圖卡**；單點是值卡，沒有連買／歷史趨勢 | 卡片是否碎片化？同一章節資訊太多嗎？能否區分交易流量、餘額與買賣方向？ |
| 集保／分點 | 級距1–15原比例，調整／合計留表；分點同日同源原順序前12列，標原分母 | **新完成級距比例及分點原淨買賣展示**；不是大戶增減／主力連買圖 | 基點是否難懂？是否適合分布柱狀？12列預覽與完整表是否重複、又增加捲動？ |
| 報酬可能／風險 | 沿原模型估計、相對基準、成本與資格；同屏提醒研究性質、未知與反證 | 有原估計／策略歷史結果卡，沒有通用「獲利機率」儀表或股票好壞總分 | +百分比是否仍容易被當成保證？成本／期限／實證能否看懂？不要以美化補造勝率。 |
| 我的紀錄／回訪 | 保存判斷、最近研究、研究時間軸及原件重開；保存時版本和最新資料分開 | 已有時間軸／紀錄與回訪；不等於所有前後績效都已視覺化 | 第一天空白如何起步？隔天能否立即理解「我當時為何關注、現在變了什麼」？ |
| 自選／持倉 | 原持倉與共用證據、交易歷史、覆盤、聲明持倉、籌碼監控與價格／策略對照等 | 保留既有呈現；未在本輪全面重新美化或做新實圖驗收 | 子頁過多嗎？持股下跌時，能否先看曝險與已知事實，而非先讀工程警告？ |
| Paper／配置／壓力 | 模擬帳、配置封存、情境壓力與人工確認；與真實持倉、研究原件保持身份分離 | 有既有預覽／表單，**不宣稱完整配置視覺化已驗收** | 一般人能否分清研究、模擬與真持倉？前置拒絕是否說清楚下一步？ |
| 策略庫／回測／比較 | 規則、風險、成本先呈現；參數來源展開；原績效／回撤／成本卡、同筆權益預覽、策略比較及原明細返回 | 已有結果卡、權益曲線與比較；不重算金融結果 | 是否過度專業？找策略→設定→執行→理解結果→比較是否直覺？ |
| ML研究 | 個人H20／Shadow等研究入口，沿各自模型、期限、原估計及資格限制 | 有既有研究展示；本輪未全面重做模型UI | 內部代號是否出現在日常路徑？是否讓人把研究模型當成已驗證推薦？ |
| 系統／資料／排程／儲存 | 更新、來源狀態、營運診斷與儲存維護有各自入口；日常頁保留必要警示 | 主要是狀態、診斷、清單；**不是已完成的統一營運儀表板** | 哪些是使用者必須知道的？哪些應留管理頁？資訊是否可分為「現在可用什麼／下一步／進階原因」？ |

## 7. 請 reviewer 回答的問題

1. 十秒內能否回答：今天市場如何、有哪些值得研究、為什麼、要注意什麼、下一步是什麼？請依實圖作答。
2. 是否仍需要太多切頁／展開？哪些資訊應提升到首頁或個股摘要，哪些反而應移入進階？請畫出建議層級。
3. 新圖卡是否只是「把表格換成橫條」？請分別提出營收、財報、法人、信用與集保的合適圖型，交代資料前置條件。
4. 四組直接顯示、其餘展開的策略，是否會讓信用、集保或分點重點被較多法人值卡擠到後面？應按資訊面向而非輸入順序編排嗎？
5. 字級、密度、留白、對齊、色彩語意、卡片層級與按鈕主次是否一致？請找具體畫面及反例，不只說「更現代」。
6. 日期、單位、成本、模型期限、缺件與限制是否能讀懂？內部代號、來源ID、品質原碼是否仍過度外露？
7. 有資料／部分／無資料／讀取失敗／首次使用／持股下跌時，使用者是否都知道可以做什麼？
8. 保存時結果與最新資料、真持倉與Paper、實績與模擬是否足夠容易分清？返回是否保留原選擇？
9. 900／1280／1500以上寬度及125%／150%縮放是否保持好讀？哪些操作只靠hover、顏色或不明確圖示？
10. 哪三個改進能以最少改動帶來最大體驗提升？哪些現有部分應明確保留，避免為改而改？

建議輸出格式：

| 優先序 | 畫面／步驟 | 具體證據 | 使用者困難 | 建議改法／草圖 | UI或資料依賴 | 驗收方式 |
|---|---|---|---|---|---|---|

請另附：整體評價與信心、已看／未看畫面、推薦資訊架構、分階段改進清單。評分可用1–5，但每項必須有證據；沒有看過的頁面標「未評」，不要給整站一個假精確總分。
