**日常研究143，固定來源 `bb09f218bba1`。** 雙擊 [Launch-Baldr.cmd](../../output/trial/Baldr-Daily-Research-143/Launch-Baldr.cmd)。本版包含月營收值前置、窄頁條件與結果可捲、清空代碼按鈕、收藏公司名稱及同源個股回訪修正。完整步驟見[包內指南](../../output/trial/Baldr-Daily-Research-143/TRIAL_GUIDE.md)，限制見[已知問題](../../output/trial/Baldr-Daily-Research-143/KNOWN_ISSUES.md)，固定身分見[交付收據](../../output/trial/Baldr-Daily-Research-143/DELIVERY_RECEIPT.json)。

## 第一次啟動

1. 首次啟動前，把**完整143資料夾**放到要使用的位置，再雙擊啟動器。首次會核對原件並建立`state/`，請保留命令視窗；本機新位置實測537.875秒，原期限600秒。
2. 後續沿同一入口使用，保存內容留在本包。已建立state後維持位置，不刪state重設；舊139、141c及私人資料不自動匯入。
3. 只設定可執行`Launch-Baldr.cmd --prepare`，設定完成後用`--check`核啟動資訊。失敗時保留錯誤、pending／failure與整包供核對。

已驗本機新位置、正常固定EXE與同版新程序受改讀回及啟動器正反SHA。完整跨機、已用state搬移、私人owner-migration、其他DPI與真人接受仍各自待驗；143首次設定原件與142的600秒FAIL分別保存，詳[143 QA](../06_qa/BALDR_DATA_POLICY_IMPLEMENTATION_20261014.md#increment143-setup-work-scheduling)。

## 四條主要流程

| 要做的事 | 操作與資料範圍 |
|---|---|
| A．市場、一般個股與營收 | 市場探索 → 大盤指數 → 檢測市場狀態；一般個股輸入2317、2330、2382或2454，載入後看價格／技術或基本面／營收財報。一般價庫到2026-09-23，大盤到10-14。三公司有半年比較，2382先列月營收五列。 |
| B．價格選股、個股、比較與收藏 | 推薦分析 → 每日研究條件 → 價格選股；選10-16來源，按代碼框旁「清空代碼」、選MA5／MA20金叉再套用，可得39檔。雙擊2506或8933進主視窗同源個股，返回原查詢。可明選2–5股比較或保存收藏。 |
| C．清單與持倉回訪 | 觀察清單的2506示範收藏顯示太設，雙擊直接開原來源個股，返回保留查詢／比較籃；8933顯示愛地雅。持倉在四卡下方，唯一精確代號／名稱可互補，私人持倉初始空白。 |
| D．回測、保存與歷史 | 策略回測的研究歷史查找可開三筆示範，查看保存規則、原結果及返回；Registry可選2–5筆同股同窗保存策略作逐日訊號對照。窄視窗以編輯設定／查看結果切換，結果區可捲動。 |

B的「清空代碼」只清代碼，保留MA等其他條件；「顯示此來源全部股票」會清其他篩選。來源只有完成strict核驗後才標已核驗；metadata本身不代表核驗。窄頁可垂直捲到條件、按鈕與結果表。

B／C使用10-16的價格研究來源，和A的四股一般價庫分開。2506／8933在原來源可看120列；切「改用一般個股查詢」後，四股庫缺這兩股仍不可用。顯示名稱不會補出價格，也不改原收藏身分、hash或來源用途。

「個股研究 → 基本面／營收財報」先列月營收五列；詳細來源可展開「來源、單位與使用限制（展開）」。2026-09當月325,300、前月423,971、去年同月184,109，單位均為**百萬元（TWD）**；月增-23.3%、年增76.7%，保留官方0.1%披露精度。

2382半年財報下載仍導向驗證頁，因此半年五指標與去年同期比較不可用；月營收不替代該財報、不加總推算累計、不進評分或歷史回測。2317、2330、2454可看2026-H1對2025-H1五列比較。未提供方向的歷史漲跌仍不補值。
