## 這版先試什麼

本輪解除價格選股後無法在主個股頁查看同份價量的斷點。建議直接試「選股 → 同源個股 → 返回 → 比較 → 收藏 → 重開」，不必重驗未改的全部功能。

| 主要任務 | 入口與可用範圍 |
|---|---|
| 看市場、查一般個股 | 市場探索／個股研究；一般價庫只有2317、2330、2382、2454，截至2026-09-23。 |
| 價格選股、個股、比較與收藏 | 推薦分析 → 每日研究條件 → 價格選股；明選2026-10-16的1,989宣告／1,951處理來源，MA5／MA20金叉可得39檔。雙擊8933或2506會到主視窗「個股研究｜價格選股原來源」，看原120列價量與五規則，再返回原查詢、比較與收藏。 |
| 觀察清單與持倉回訪 | 從收藏精確重開原來源；持倉位於四卡下方，唯一精確代號／名稱可互補，未綁來源部位可回一般個股重載。 |
| 回測、保存與歷史 | 保存原run，從歷史核原條件／規則、開明細並返回。窄視窗用「查看實驗結果」／「編輯回測設定」切換，結果可捲動；批次逐股不能當同一組合績效比較。 |

在同源個股頁按「改用一般個股查詢」才會離開選股來源；一般庫缺8933或2506時仍無資料。兩庫日期與範圍不同，不自動合併或接入回測。條件、兩股比較及收藏重開的五步操作在包內指南。
