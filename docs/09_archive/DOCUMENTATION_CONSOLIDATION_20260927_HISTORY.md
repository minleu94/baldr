## 保存與驗證

Hub、索引、Snapshot、手冊更新歷史的歸檔位置由 [Archive README](../09_archive/README.md) 導覽。原內容只加歷史標示、調整相對連結及換行；逐次提交可復原。手冊的操作段落保留於正文或附冊，不把可操作步驟當作歷史狀態刪除。覆蓋表只保留文檔覆蓋用途，移除舊進度數字並回到 Snapshot；排程數量明示為 2026-09-09 歷史觀測。

本機盤點腳本、原始 bytes、SHA、逐檔 JSON 與連結基線在 ignored `output/qa/documentation_consolidation_20260927/`，不提交 raw output。文檔編碼、相對連結、搬移內容與深連結導向檢查屬本次驗證；不修改程式功能，未執行正式資料寫入、scheduler、訓練或交易。

既有 7 個相對連結目標缺失涉及歷史程式路徑、分派文件及本機 fixture；新導航與搬移未新增缺失。歷史固定證據保留原樣，不能藉由改寫收據消除當時路徑。此限制不代表目前操作入口不可用。
