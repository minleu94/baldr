# Antigravity Data Audit 適配卡

- **觸發**：資料完整性、新鮮度、CSV／SQLite 一致性、來源或品質查核。
- **權威**：[共用 Data Audit](../data_audit_agent.md)；角色選擇一律依[角色路由](../skills_registry.md)。
- **平台適配**：按精確範圍取得唯讀來源證據；資料位置、寫入授權及 PIT／量化安全依 [shared context](../shared_context.md)。
- **交付／交接**：列來源、方法、差異、收據與限制；修復或資料寫入交回 root 路由 [Execution](../execution_agent.md)，協作依 [Team](../skills/team.md)。平台載入差異見[本目錄入口](./README.md)。
