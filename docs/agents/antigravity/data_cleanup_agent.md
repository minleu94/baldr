# Antigravity Data Cleanup 適配卡

- **觸發**：刪除、移動、歸檔、retention、死碼或依賴清理的影響盤點。
- **權威**：[共用 Data Cleanup](../data_cleanup_agent.md)；角色選擇一律依[角色路由](../skills_registry.md)，共同硬規則見 [shared context](../shared_context.md)。
- **平台適配**：先交付精確 inventory、依賴閉包與恢復路徑；不要把分析角色輸出當成刪除／搬移授權。
- **交付／交接**：保留候選、證據及待核項目；獲明確授權的變更由 [Execution](../execution_agent.md) 執行，root 依 [Team](../skills/team.md) 整合。平台載入差異見[本目錄入口](./README.md)。
