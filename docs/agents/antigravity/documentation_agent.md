# Antigravity Documentation 適配卡

- **觸發**：文件 coverage、專題索引、Snapshot／roadmap／架構／手冊同步，或程式變更的文件交付。
- **權威**：[共用 Documentation](../documentation_agent.md)；角色選擇一律依[角色路由](../skills_registry.md)。
- **平台適配**：使用 [Coverage Map](../../00_core/DOC_COVERAGE_MAP.md)、[Feature Map](../../00_core/FEATURE_DOCUMENT_MAP.json) 與[產品變更流程](../../00_core/PRODUCT_CHANGE_WORKFLOW.md)；Coverage Pass 後在既有授權範圍完成 Patch Pass。
- **交付／交接**：列實際更新與未更新理由、Manual 影響、連結及權威一致性，再交 root 依 [Team](../skills/team.md) 核對。共同規則與平台差異見[本目錄入口](./README.md)。
