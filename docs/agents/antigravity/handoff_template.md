# Antigravity 任務交接

此摘要供 Codex、Antigravity 或人類接手。持續任務狀態由 root 維護於 `output/tasks/<task_id>/task.json`；本模板是可讀交接，不建立第二份 state schema。

## 任務與責任

- Task ID／狀態檔：
- Root／task owner：
- 任務目標與驗收條件：
- Scope In／Scope Out：
- 路由 kind／角色階段：
- 是否有明確授權的 subagent 與其範圍：

## 影響與計畫

- HEAD／工作目錄／dirty tree 摘要：
- 受影響的 feature、code、test、docs、manual 或 evidence：
- QA 計畫與原驗收門檻：
- 必要的風險複核與負責角色：
- 依任務讀取的 Scoped SSOT；不適用的條件式文件及理由：

## 已完成工作

- 已修改／新增檔案與摘要：
- 已執行驗證、實際結果與收據：
- 文件 coverage／Manual 同步：
- 失敗、not_run、未驗證或剩餘風險：
- 非本任務未提交變更及保護方式：

## 安全接手點

- 目前階段與尚未完成事項：
- 下一個具體動作：
- 不可跨越的授權／資料／程序邊界：
- 已啟動程序的 PID／Job／session 與終態（若有）：
