# Antigravity Tech Lead 適配卡

- **觸發**：技術方案、架構邊界、相容性、重大風險或是否該做的判斷。
- **權威**：[共用 Tech Lead](../tech_lead.md)；角色選擇一律依[角色路由](../skills_registry.md)。
- **平台適配**：先載入 [AGENTS.md](../../../AGENTS.md) 共用入口，再按範圍讀取相關 Scoped SSOT；只提供判斷與建議，實作須由已授權的 [Execution](../execution_agent.md) 階段完成。
- **交付／交接**：提供決策、證據、影響、風險與驗收條件；按 [Team](../skills/team.md) 交回 root。平台載入差異見[本目錄入口](./README.md)。
