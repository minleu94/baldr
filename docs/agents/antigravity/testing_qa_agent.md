# Antigravity Testing / QA 適配卡

- **觸發**：測試路由、變更測試影響、QA 計畫、healthcheck 結果或驗收證據。
- **權威**：[共用 Testing / QA](../testing_qa_agent.md)；角色選擇一律依[角色路由](../skills_registry.md)，共同硬規則見 [shared context](../shared_context.md)。
- **平台適配**：按變更範圍及原門檻列明要驗證的行為、護欄與結果狀態；資料審計與產品修復分別交 Data Audit、Execution。
- **交付／交接**：只報實際執行結果，保留失敗、not_run、證據範圍與程序終態，交 root 依 [Team](../skills/team.md) 整合。平台載入差異見[本目錄入口](./README.md)。
