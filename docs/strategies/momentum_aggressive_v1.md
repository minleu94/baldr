# 暴衝策略 (Momentum Aggressive v1.0)

## 策略理念（Why）

### 核心思想
本策略以總分門檻及較短的訊號確認期執行動能規則。Registry 將 Trend／Breakout 列為適用情境，並以「快速獲利」描述設計意圖；這些標籤不代表已驗證的績效或預期收益，`risk_level=high` 也不是經實證校準的風險分數。

### 為什麼選擇這個策略？
1. **策略適用情境**：Registry 標記 Trend／Breakout；這是策略 metadata，不表示執行流程一定會依市場 Regime 自動篩選或切換策略。
2. **較短確認期**：預設買入與賣出確認天數都是 1；這描述規則設定，不證明訊號更早或績效更好。
3. **分數門檻出場**：預設賣出門檻為 50；它不是固定獲利目標，也不保證保護獲利。

### 適用場景
- Registry 標記的 Trend／Breakout 適用情境；實際 Regime 判定與策略路由依目前程式及操作流程為準
- `risk_level=high` 是策略 metadata，不能單獨用來判定使用者是否適合此策略

### 不適用場景
- Registry 標記的 Reversion 不適用情境；這不代表系統一定會自動排除該策略

## 風險屬性

- **Registry 風險標籤**：高（`high`）；這不是經實證校準的風險分數。
- 本文件未連結固定版本的績效研究收據，因此不據此宣稱預期報酬、最大回撤或實際交易頻率。
- 執行器預設參數見 [MomentumAggressiveExecutor](../../decision_module/strategies/momentum_aggressive_executor.py)；預設未設定資金配置比例、停損或停利。

## 策略參數

- **門檻模式**：`fixed`
- **買入／賣出分數門檻**：70／50
- **買入／賣出確認天數**：1／1
- **冷卻期**：2 天；這是兩次交易間的規則限制，不代表實際交易頻率

## 注意事項

1. 執行器預設未設定部位權重或停損／停利；不要將文件以外的百分比當成系統預設或已驗證的風控值。
2. Trend／Breakout 是此策略 metadata 的適用情境；這段說明不表示系統會自動切換策略或保證 Regime 篩選一定執行。
3. Reversion 是標記的不適用情境；任何實際策略選擇與部位／風控設定都須依目前操作手冊及單獨的研究證據判讀。
