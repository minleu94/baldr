# 穩健策略 (Stable Conservative v1.0)

## 策略理念（Why）

### 核心思想
本策略以總分門檻、較長的訊號確認期及冷卻期執行規則，不計算基本面估值或內在價值。Registry 將 Reversion 列為適用情境，並以「穩定報酬」描述設計意圖；這些標籤不代表已驗證的績效或預期收益，`risk_level=low` 也不是經實證校準的風險分數。

### 為什麼選擇這個策略？
1. **策略適用情境**：Registry 標記 Reversion；這是策略 metadata，不表示執行流程一定會依市場 Regime 自動篩選或切換策略。
2. **較長確認期**：預設買入與賣出確認天數都是 3；這描述規則設定，不證明誤判較少或績效較穩定。
3. **冷卻期**：預設冷卻期為 5 天；這是兩次交易間的規則限制，不代表實際交易頻率或成本已降低。

### 適用場景
- Registry 標記的 Reversion 適用情境；實際 Regime 判定與策略路由依目前程式及操作流程為準
- `risk_level=low` 是策略 metadata，不能單獨用來判定使用者是否適合此策略

### 不適用場景
- Registry 標記的 Trend／Breakout 不適用情境；這不代表系統一定會自動排除該策略

## 風險屬性

- **Registry 風險標籤**：低（`low`）；這不是經實證校準的風險分數，也不代表實際最大回撤較小。
- 本文件未連結固定版本的績效研究收據，因此不據此宣稱預期報酬、最大回撤或實際交易頻率。
- 執行器預設參數見 [StableConservativeExecutor](../../decision_module/strategies/stable_conservative_executor.py)；預設未設定資金配置比例、停損或停利。

## 策略參數

- **門檻模式**：`fixed`
- **買入／賣出分數門檻**：55／45
- **買入／賣出確認天數**：3／3
- **冷卻期**：5 天；這是兩次交易間的規則限制，不代表實際交易頻率

## 注意事項

1. **部位與風控**：執行器預設未設定部位比例、停損或停利；不能因 `risk_level=low` 推定可增加部位。
2. **市場狀態監控**：Reversion 是此策略 metadata 的適用情境；這段說明不表示系統會自動切換策略或保證 Regime 篩選一定執行。
3. **不適用情境**：Trend／Breakout 是標記的不適用情境；實際策略選擇仍須看目前程式與操作手冊。
4. 較長確認期會改變規則確認條件；對訊號時間與績效的影響需以固定版本研究判讀。
