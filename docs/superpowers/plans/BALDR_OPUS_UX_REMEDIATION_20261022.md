## 判斷與完成界線

採納核心批評：現有成果證明圖卡與動線已實作、資料守衛存在，但不足以證明第一眼好懂、美觀或操作直覺。不能再把「原值能畫出來」當成完整視覺化設計已完成。

初審基線已由程式確認：`ThemeTokens.data_positive` 為綠、`data_negative` 為紅，當時價量及題材使用這兩者；`_render_flows` 接續法人與其他面向，`_add_research_visuals` 只直接顯示前四組。因此方向色問題成立，其他面向被擠後的風險亦成立；本輪另以完整欄位fixture補證，再改為獨立市場方向token與固定面向。

保留：K線／摘要並排、支持／反證／未知、題材雙端與覆蓋分母、策略結果卡與權益、缺值不補零、原表可查、保存版與最新版分離，以及原件返回。不能用縮短文案隱藏未知、限用或來源失配。

一項細節需校正：最新圖卡的逐列detail已有可見Label及accessible資訊，不是全部只在tooltip；但原籌碼表格的可得時間／來源仍部分依賴hover。因此應改善明細入口與重複資訊，而非依「全部不可見」的前提重做元件。
